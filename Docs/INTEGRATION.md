# Runtime integration contract

All runtime code uses namespace `MadeInArizona`. Unity 6000.5.5f1, URP 17.5.0, Input System 1.19.0. Local procedural assets are deliberately original prototype art.

## Ownership
- Root: GameManager, GameUI, CameraController, bootstrap scene/build configuration, integration and validation.
- Vehicle/combat agent: InputManager, VehicleController, VehicleStats, VehicleDamage, WeaponSystem, ProjectileSystem, ExplosionSystem, DestructionSystem, EnemyAI, SpawnManager.
- Content agent: data definitions and ContentCatalog, SaveSystem, GarageManager, MissionManager, DialogueSystem, AudioManager/MusicManager.
- World agent: WorldBuilder, VehicleVisual, SuzukiDog and original modular procedural geometry/materials. No editor/build files.

## Agreed public API (extend if useful, tell others)
`GameManager.Instance`: singleton; fields/properties `Player` (VehicleController), `World` (WorldBuilder), `Mission` (MissionManager), `Save` (SaveData), `State` (GameState enum Garage, Playing, Paused, Won, Lost), `SelectedMission` int; `StartMission(int)`, `ReturnToGarage()`, `Pause()`, `Resume()`, `CompleteMission()`, `FailMission()`, `Notify(string)`. `IsPlaying => State == Playing`.

Data: `VehicleDefinition : ScriptableObject`: id/displayName/description, mass, horsepower, torque, maxSpeed, grip, turnSpeed, maxHealth, rideHeight, wheelbase, trackWidth, color(Color), cost(int), unlockMission(int), drivetrain(Drivetrain enum FWD,RWD,AWD), differential(Differential enum Open,LimitedSlip,Locked), suspensionTravel, springStiffness, damping, finalDrive. `VehiclePart : ScriptableObject`: id/displayName/description/category strings, cost(int), mass/hpMultiplier/gripMultiplier/coolingMultiplier/healthBonus floats, unlockMission(int). `WeaponDefinition : ScriptableObject`: id/displayName/description, damage, fireRate, speed, blastRadius, heat, projectileColor. `MissionDefinition : ScriptableObject`: id/title/region/briefing/opening/midpoint/closing/optionalObjective strings, mode(MissionMode enum Recovery,Demolition,Defense,Convoy,Race,Rescue,Boss,Escape,Salvage), reward(int), enemyCount(int), timeLimit(float), targetCount(int). `DriverDefinition : ScriptableObject`: id/displayName/biography/perk/line strings, color(Color), repairMultiplier/powerMultiplier/gripMultiplier floats. `ContentCatalog`: static properties `Vehicles`, `Parts`, `Weapons`, `Missions`, `Drivers` as arrays; `EnsureLoaded()` runtime fallback creates ScriptableObjects if no authored resources; editor can persist those arrays to Resources/Content. All fields public serializable.

`SaveData`: money(int), salvage(int), reputation(int), selectedVehicle(int), selectedDriver(int), unlockedMission(int), completedMissions(List<int>), ownedParts(List<string>), installedParts(List<string>), bestScores(List<int>), dogCosmetic(int), settings(GameSettings). `GameSettings`: master/music/engines/weapons/dialogue/environment/shake/uiScale floats; quality/difficulty/aimAssist int; subtitles/fullscreen bool; bindingOverrides string. `SaveSystem.Load()`, `SaveSystem.Save(SaveData)`, `SaveSystem.Path` string. `GarageManager.StatsFor(VehicleDefinition,SaveData)` returns VehicleStats; `BuyPart(VehiclePart,SaveData)` bool; `TogglePart(VehiclePart,SaveData)`; `SelectVehicle(int,SaveData)` bool. Content agent implement calculation once VehicleStats known.

`VehicleStats`: static `From(VehicleDefinition)` returns mutable stats with mass/horsepower/torque/maxSpeed/grip/turnSpeed/maxHealth/rideHeight/wheelbase/trackWidth/suspensionTravel/springStiffness/damping/finalDrive/cooling floats, drivetrain and differential enums.
`InputManager.Instance`: Move(Vector2), Aim(Vector2 world XZ), Primary/Secondary/Tertiary/Handbrake/Boost/Repair/Interact/PausePressed bool, UsingGamepad bool; `SetEnabled(bool)`; `Actions` InputActionAsset if using new system. Input keyboard WASD, aim mouse, LMB primary, RMB rocket, Q tertiary shotgun, Space brake, Shift boost, R repair, E interact, Esc pause. Gamepad sticks with right stick auto fire, LT rocket, RT shotgun, shoulders boost/repair, South interact, East brake, Start pause.
`VehicleController`: `Initialize(VehicleDefinition,VehicleStats,bool isPlayer)`; `Damage` VehicleDamage; `Weapons` WeaponSystem; `Body` Rigidbody; `Visual` Transform; `IsPlayer` bool; `SpeedKph`, `RPM`, `EngineTemperature`, `Throttle` floats; `SetAIInput(Vector2 move,Vector3 aim,bool fire)`; `Repair(float amount)`. Model is created with `VehicleVisual.Build(definition, transform, bool enemy)` returns Transform visual root, has child `Turret` and optional wheels. Vehicle forward +Z, Y-up, nominal sizes ~2x4m. Inputs camera aligned, camera faces north (+Z), fixed offset (0,32,-25).
`VehicleDamage`: Health/MaxHealth floats, IsDead bool; `ApplyDamage(float,Vector3 hitPoint,GameObject source)`; `Repair(float)`; normalized Engine/Radiator/Transmission/Wheels/Suspension float component values. `WeaponSystem` public `FirePrimary(Vector3)`, `FireSecondary(Vector3)`, `FireTertiary(Vector3)`. `ExplosionSystem.Detonate(Vector3,float radius,float damage,GameObject source,ExplosionKind kind)` static; enum Gasoline,Propane,Ammunition,Electrical,Grenade,Rocket,FuelTank,Vehicle,Massive. `ExplosionSystem.Burst(Vector3,Color,int,float)` static cosmetic burst. `DestructionSystem`: `Configure(float health,ExplosionKind kind,bool explosive,int score)`; `ApplyDamage(float,Vector3,GameObject)` public. `EnemyAI`: `Initialize(VehicleController target,int archetype)`; `SpawnManager.Spawn(Vector3,int,VehicleController)` returns VehicleController.

`WorldBuilder.BuildGarage()` and `BuildMission(int missionIndex)` clear previous geometry beneath own transform; `PlayerSpawn` Vector3, `ObjectivePoints` List<Vector3>, `EnemySpawns` List<Vector3>, `ExtractionPoint` Vector3; `ObjectiveLabel` string; `CreateMarker(Vector3,Color,string)` returns GameObject; `SurfaceAt(Vector3)` static returns SurfaceKind enum Asphalt,Dirt,Sand,Gravel,Mud,Water,Rocks,Oil,Debris. Map coordinates X [-100,100], Z [-85,140], ground at Y=0; player starts (0,1,-60); garage vehicle at (0,1,0). Build world dense enough to be attractive; driving routes >= 10m wide; use primitive colliders. Marker colliders disabled. Parent environment to WorldBuilder; parent all gameplay dynamic entities to world root to cleanly reset. `SuzukiDog` cannot receive damage.

`MissionManager`: `Begin(MissionDefinition,int)`; `Tick(float)` called by GameManager only in Playing; `RegisterKill()`, `RegisterDestruction(int,Vector3)`, `RegisterPickup(string)`; Objective(string), Stage(int), Score(int), Kills(int), DestructionCount(int), Elapsed(float), Remaining(float), Combo(int), Progress(float) public read access; `ObjectivePosition` Vector3. Mission handles progression/extraction proximity, spawns waves via SpawnManager; runtime manager components are attached to persistent GameManager root, rebuilt state on Begin.
`DialogueSystem.Instance`: `Say(string speaker,string text,float duration=7)`, `Skip()`, Speaker/Text strings, Active bool. Mission text has short lines. `AudioManager.Instance`: `PlayShot(Vector3,int)`, `PlayExplosion(Vector3,float)`, `PlayUI()`, `SetCombat(bool)`. Runtime component self-initializes audio. Engine loop may be on audio manager driven from player values. Original synthesis only, no external copyrighted media.
`CameraController.Instance`: `Target` Transform; `Shake(float)`; garage and mission camera modes via GameManager.State. Root manages URP volume and graphics quality.

No agent starts Unity until root requests: avoid shared asset database locking. Keep source compilation compatible with Unity C# language level, no editor references in runtime scripts. Report integration mismatches immediately.
