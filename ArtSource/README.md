# Original procedural asset source

The authoritative editable sources are `Assets/MadeInArizona/Scripts/World/VehicleVisual.cs`, `RoadsideProps.cs`, `WorldArt.cs`, `WorldBuilder.cs` and `SuzukiDog.cs`. They create original prototype geometry in metres, Y-up, vehicle forward +Z. No third-party vehicle model, real vehicle badge, character likeness or music sample is included. Blender was not required to implement this slice; these models are deliberately identified as procedural prototype art.

The editor Prepare action exports reusable vehicle visual prefabs, materials, mesh assets, propane and crate prefabs. Vehicle hardpoints are named Turret, Muzzle, Wheel_FL, Wheel_FR, Wheel_RL, Wheel_RR. Replace these with custom authored assets at VehicleVisual.Build while preserving the named anchors and dimensions used by VehicleStats.

Original audio and music PCM generation is in `Scripts/Audio/AudioSynthesis.cs`. The score has separate garage and combat arrangements and contains no external samples.

## Third-party smoke and fire maps

Smoke/fire now use Unity's free six-way baked fluid texture samples, linked directly from the user's reference article. They are rendered with the project's custom URP shader and pooled ParticleSystem emitters. They are not generated by this project and are not VFX Graph assets. See `Assets/MadeInArizona/Resources/SixWay/SOURCE.md` for exact original filenames and provenance.
